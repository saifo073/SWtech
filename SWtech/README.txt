SWtech - Projeto PHP + MySQL

1. Coloque esta pasta dentro de htdocs no XAMPP.
2. Ligue Apache e MySQL.
3. Abra o phpMyAdmin.
4. Importe o arquivo banco.sql.
5. Confira app/cons.php:
   servidor = localhost
   usuario = root
   senha = vazia
   banco = swtech
6. Coloque suas imagens na pasta imagens com os nomes indicados no arquivo COLOQUE_SUAS_IMAGENS_AQUI.txt.
7. Acesse http://localhost/SWtech/

Operacoes do banco ficam centralizadas em banco.php e os formularios usam POST.
